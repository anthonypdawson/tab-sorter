Tab Sorter Settings

AI is optional and off by default. The core grouping, dedupe, and stale checks work with no AI and send nothing anywhere.

Custom keyword groups

Generic groups (Work, Code, Email, Media) ship in the extension. Add your own groups here — these live only in your browser settings, never in the shipped code, so personal project names stay private. Custom groups win over generic ones.

Format: a JSON list of objects with a name and a keywords list. A tab matching any keyword goes in that group.

AI backend

Ollama (local)


Example: run ollama serve and ollama pull qwen2.5:3b first. Tab titles/URLs stay on your machine. If AI grouping still reports a 403, see the Ollama note in the README: it is Ollama rejecting the extension origin, and the fallback is OLLAMA_ORIGINS plus a full Ollama restart. Chrome built-in AI, below, can also be disabled by enterprise policy.

Cloud (only if you choose this)



Warning: with a cloud backend, tab titles and URLs are sent to that endpoint when you press AI group. The key is stored in chrome.storage.local on this machine only.
